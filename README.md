---

## 💻 Sobre o projeto

Fintech é uma landing page desenvolvida para apresentar uma solução moderna de gestão financeira digital.

O desafio proposto para este projeto foi a criação de uma interface elegante e responsiva para uma fintech, destacando funcionalidades como controle financeiro, análise de desempenho, relatórios inteligentes e acompanhamento de crescimento financeiro. Neste projeto, foram aplicados conceitos de HTML5 e CSS3 para construir uma experiência visual moderna, com foco em usabilidade, acessibilidade e design responsivo.

---

## ⚙️ Funcionalidades

- [x] Navegação simples e intuitiva através do menu principal.
- [x] Apresentação dos principais benefícios da plataforma financeira.
- [x] Seção informativa sobre controle financeiro inteligente.
- [x] Exibição de gráficos e indicadores de desempenho.
- [x] Design responsivo para diferentes tamanhos de tela.
- [x] Footer com links rápidos e área de inscrição para novidades.
